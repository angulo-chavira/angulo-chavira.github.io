Editor de recursos privados

Agrega enlaces y notas; el archivo se cifra en este navegador antes de descargarlo. El sitio no recibe ni almacena tu frase de paso.

Antes de empezar: elige una frase de paso larga que puedas conservar. Si la pierdes, no hay forma de recuperar el contenido cifrado. Esta herramienta no está pensada para almacenar documentos confidenciales ni contraseñas.

El archivo cifrado se guarda en data/private-resources.enc.json. Si el navegador pregunta, confirma la descarga.
