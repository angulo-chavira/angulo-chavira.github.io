Administrador del sitio

Desde aquí puedes actualizar la información de las páginas. Los cambios se guardan primero como borrador en este navegador; al final puedes enviarlos a GitHub con un commit.

Lo que subas al repositorio será público. Puedes subir imágenes, bases de datos y PDFs que tengas permiso de compartir. No subas comprobantes, expedientes ni archivos confidenciales. Los documentos privados deben quedarse en un servicio con acceso restringido.
Conectar GitHub por primera vez
  1. En GitHub crea un token detallado (fine-grained), con vencimiento, acceso solo al repositorio de esta página y permiso Contents: Read and write.
  2. Pega el token aquí y pulsa Conectar. El token permanece en memoria en esta pestaña; no se guarda en el repositorio ni en el borrador.
  3. Elige una sección, edita sus datos y pulsa Guardar cambios y hacer commit. GitHub Pages publicará el cambio después del commit.

Abrir la página de GitHub para crear el token ↗

Nunca pegues el token en un correo, documento o conversación. Al cerrar esta pestaña tendrás que introducirlo de nuevo.
