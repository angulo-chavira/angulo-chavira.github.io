Editar publicaciones

Esta herramienta modifica el archivo de datos del catálogo, no el diseño del sitio. Los cambios se procesan en este navegador y no se envían a un servidor.

Todo lo que escribas aquí será público al reemplazar el archivo del sitio. No agregues comprobantes, datos personales ni información confidencial.
  1. Agrega o corrige registros en esta página. Los cambios se guardan como borrador local en este navegador.
  2. Descarga publications.json y reemplaza data/publications.json en GitHub.
  3. GitHub Pages actualizará el catálogo después del commit. No necesitas tocar HTML, CSS o JavaScript.
